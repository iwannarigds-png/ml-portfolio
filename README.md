# Medical Appointment No-Show Predictor (Explainable AI)


An end-to-end Machine Learning solution designed to predict patient no-shows and interpret individual predictions using **SHAP (SHapley Additive exPlanations)** values. Built with **Python**, **Scikit-Learn**, and **Streamlit**.

---

##  Key Features

* **Predictive Modeling:** High-accuracy Random Forest classifier trained on clinical & demographic factors.
* **Explainable AI (XAI):** Integrated SHAP waterfall & force plots to explain *why* a specific patient is predicted to miss an appointment.
* **Interactive Web Dashboard:** Intuitive UI built with Streamlit allowing real-time parameter tuning and risk calculation.
